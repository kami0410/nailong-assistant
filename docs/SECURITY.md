# 安全说明

奶蛙助手能够操作鼠标键盘、读写文件和运行命令。权限确认减少误操作，但它不是系统沙箱。

## 权限与提示词的边界

| 行为 | 实际约束 |
| --- | --- |
| 删除文件 | delete_path 走回收站并要求确认；批准的 run_command 仍能执行其他删除方式 |
| 付款、下单、发消息 | 系统提示词要求禁止；鼠标、键盘及命令工具不能从机制上识别并禁止所有此类行为 |
| 系统变更 | permissions.js 硬拒绝部分已知危险命令；Set-ExecutionPolicy、netsh、takeown、icacls 等仅标记为高风险，允许用户批准 |
| 文件保护 | 文件工具检查源和目的路径；主机层解析现有目录的真实路径，保护应用代码、数据和部分系统目录。命令工具不受同一文件沙箱约束，路径检查也不消除并发替换风险 |
| 计划模式 | 每项新任务须先批准 propose_plan 才可执行非只读工具；批准计划后，高危工具仍单独确认 |

| 模式 | 只读工具 | 中危工具 | 高危工具 |
| --- | --- | --- | --- |
| 每步确认 | 执行 | 先问 | 始终先问 |
| 自动执行 | 执行 | 执行 | 始终先问 |
| 只读 | 执行 | 拒绝 | 拒绝 |

两套引擎共用权限判定。禁用工具会被拒绝执行；pi 工具清单在重启内核后刷新。停止操作拒绝挂起的审批、清除 pi 排队消息并请求中止；已经发出的原生操作不保证能撤回。

## 密钥与数据

- 新保存的 API Key 使用 Windows CurrentUser DPAPI 直接加密，写入数据根的 agent.json，不依赖 Electron Local State 的延迟写回。旧 Electron safeStorage 密文仍可读取，下次保存时迁移。加密或写入失败会拒绝保存并在界面报错；启动解密失败会保留原密文。新版密钥依赖原 Windows 账户，旧密钥还需保留 .userdata 中的加密上下文。升级时请保留整个数据目录。
- 模型调用会把凭据、会话及必要的截图/工具结果传给用户配置的服务商。截图可能含有其他应用的敏感信息。
- pi 通过带鉴权的本机回环取得自定义 provider 凭据；应用不会主动把这些凭据写入 pi 的 auth 文件。用户扩展和 MCP OAuth 有自己的数据和凭据存储。
- 会话、日程、剪贴板历史及记忆通常是明文文件。剪贴板历史默认开启，可关闭和清空。
- 数据根按 NAILONG_DATA_DIR → PORTABLE_EXECUTABLE_DIR → exe 目录 → 开发源码目录 → APPDATA → TEMP 尝试可写目录。优先目录不可写时会回退；请在“关于”确认实际路径。
- 不应把运行时数据、.userdata、.cache 或个人配置一起分享为源码。

## 本地工具桥

桥仅监听 127.0.0.1 的随机端口，使用每次启动随机生成的 24 字节 token。鉴权先检查字节长度再做常数时间比较。请求体限制 8 MiB，端点仅为 /health /catalog /config /tool /notify /log。

同用户进程可能读到子进程环境或内存中的 token，从而使用这 54 个工具。回环鉴权不是对同用户恶意程序的隔离边界。获得 token 后仍须经过桥侧权限判定，但不能据此保证用户数据安全。

## 界面与第三方代码

六个窗口启用 contextIsolation、关闭 nodeIntegration，通过 preload.js 的显式接口访问主进程。HTML 带 CSP；动态内容应使用 textContent 或完整属性转义。CSP 和隔离减少渲染层攻击面，不能代替主进程授权。

bundled 模式使用数据根中的 .userdata/pi-agent，不修改全局 ~/.pi/agent。切到 system 模式会清除继承的 PI_CODING_AGENT_DIR 覆盖，再沿用系统 pi 配置。子进程仍继承普通代理等环境变量，bundled 并不是完整环境隔离。

默认关闭 pi 原生工具，显式加载奶蛙扩展，并用 --no-extensions 禁止其他扩展。启用用户扩展或 MCP 后，第三方代码可能绕开奶蛙的工具桥直接访问系统；不要把奶蛙工具权限视为它们的沙箱。bundled 使用自身配置目录；system 模式才使用系统配置。

MCP command 类型启动外部程序，url 类型连接远程服务。应用添加服务器时默认 exposure: direct；pi 的 codemode/deferred 也能通过搜索、描述与加载机制发现工具，不能把它们概括为“模型看不到”。hidden 才不会暴露给模型。MCP 启用仍依赖用户扩展开关。

pi 含独立的遥测组件。安装遥测与分析受 pi 设置控制，不能承诺整个应用及依赖绝无遥测；本次本地模型测试显式设置了 PI_TELEMETRY=0。

## 截图与验收

截图会暂时隐藏自身窗口，默认选择光标所在显示器，也支持指定显示器/区域。隐藏自身窗口不保证后续点击不会落到它上面。坐标转换保留裁剪偏移和显示器物理原点；混合 DPI 与多显示器仍需真实硬件验收。

本机测试、界面检查和本地模型夹具不能证明真实服务商、其他 Windows 版本、所有桌面背景及音频设备都正常。具体证据和未验证事项见最终审查报告。
