# 设置与助手接口配置同步修复

用户反馈：在设置中已经保存接口配置，预先创建的助手窗口仍显示空表单，要求重新输入。

根因：助手只在 init 时读取配置；设置保存的 IPC 没有发布配置变更，打开助手的事件只聚焦输入框。两个页面实际共用 agent.json，缺失的是窗口同步。设置页也会保留助手修改之前的旧值。

范围：成功保存/切换模型后广播公开配置（不包含 key 或 keyEnc）；两个页面更新地址、模型与密钥掩码，助手配置完整时进入聊天。每次打开助手重新读取当前配置；读请求期间收到更新时不允许旧结果覆盖新配置。助手自身的保存并测试流程保留可见错误提示，避免同步时提前切走。

证据：配置同步真实 Electron 5 项负例全部失败；修复后 5 项及新进程加密配置读取 1 项通过。另有先失败后通过的连接失败可见性回归。所有动态验收使用独立临时数据和本机假接口，不发送真实密钥或调用用户账户。实际安装目录已确认存在加密密钥、地址和模型，只输出是否存在，不显示其内容。

交付要求：完整语法/测试与真实窗口 audit，通过后在最终打包代码重复配置与 pi UI 回归，更新实际安装目录中的代码并备份旧文件、保留用户数据，交付单独的配置同步修复版。
