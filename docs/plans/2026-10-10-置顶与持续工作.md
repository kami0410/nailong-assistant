# 置顶与持续工作

用户要求：奶龙桌宠一直在最上面，取消最大工作时长。保持 pi 内核，保留手动停止；只取消总时长限制，现有工具调用次数和权限设置继续生效。

## 行为设计

- 桌宠显示时采用 screen-saver 层级；显示、恢复和失焦时重新提到前面。
- 每秒校准一次窗口层级，以覆盖后来出现的其他置顶窗口；使用 moveTop，不获取键盘焦点。隐藏时不自动显示，关闭时清理定时器。
- 移除启动三秒后把窗口放到桌面层的旧 pin 调用。原生显示桌面后的恢复机制继续工作。
- 移除 pi 路由计时器、工具桥截止时间、内置循环截止时间，以及设置中的总时长输入。旧 maxRuntimeMs 不再参与运行决策。
- 保留单次请求超时、重试、工具次数限制和停止按钮，避免把接口挂起误当成任务总时长。

## 验证

先用旧代码复现跨截止时间被阻止、真实 pi 被极短总时长中止以及桌宠不恢复置顶，再修改生产代码。用假时钟推进一天验证任务循环与工具调用；真实 pi 请求验证废弃设置无效，运行中的流可以手动停止。

真实 Electron 窗口夹具通过 Win32 读取 WS_EX_TOPMOST 和窗口顺序，覆盖最大化窗口、无边框全屏窗口、其他置顶窗口、置顶标记丢失、隐藏和窗口重建，并检查前台窗口保持不变。截图检查设置说明的排版。打包后复测生产模块，更新实际使用目录并核对代码与加密配置保留。

验证边界：时间推进不等于连续运行一天；未验证 Windows 安全桌面或独占全屏游戏。
